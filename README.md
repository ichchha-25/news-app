# 🚀 Basic News Submission Web Application

A lightweight Express.js backend for submitting and retrieving news articles. Designed for quick deployment and testing without environment configuration.

---

## 🔧 Tech Stack

- **Backend:** Node.js + Express.js  
- **Database:** MongoDB (via Mongoose)  
- **No `.env` file used** — port and DB URI are hardcoded for simplicity

---

## 📦 Installation

```bash
git clone https://github.com/your-username/news-app.git
cd news-app
npm install

```
server will start using:
node server.js
server running on: http://localhost:3000

news-app/
├── models/

├── routes/
